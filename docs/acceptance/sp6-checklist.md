# SP6 대화 화면 조각 실기기 체크리스트

SP6 스펙(`docs/superpowers/specs/2026-10-24-sp6-chat-generative-ui-design.md`) 13장 "실기기" 줄 넷과 1장 완료 조건 1~4, 7을 아이폰(홈 화면에 올린 PWA)에서 Dahun이 직접 해 보며 확인한다. 단계마다 날짜와 결과를 채운다. 문제가 보이면 GitHub 이슈로 남기고 "이슈" 칸에 번호를 적는다.

SP9 9.6 뒤로 할 일이 바뀌면 대화에는 한 줄 "✓ …"(활동 줄)만 남고, 되돌리기는 채팅 아래 토스트(6초)와 기록 화면에 있다. 아래 "확인 칸"은 이 활동 줄이다.

## 단계

| # | 할 일 (스펙 13장 실기기 · 1장 완료 조건) | 볼 것 | 날짜 | 결과 | 이슈 |
|---|---|---|---|---|---|
| 1 | 대화에서 날짜가 분명하지 않은 할 일을 말한다(예: "치과 예약 추가해 줘") (조건 1) | 할 일이 그럴듯한 날(모르면 오늘)로 추가되고 `ui_date_choice` 카드에 날짜 후보 2~4개와 "다른 날로 할게요". 이 답에 `ui_result` 카드는 없고 활동 줄 "✓ 추가: … → …"이 보인다 |  |  |  |
| 2 | 1의 카드에서 후보 하나를 누른다 (조건 1) | 누른 후보만 진하게 남고 다른 버튼은 꺼진다. 알림(토스트)에 확인 문구와 "되돌리기". 할 일 화면에서 그 날짜에 보인다 |  |  |  |
| 3 | 2의 토스트에서 "되돌리기"를 누른다 (조건 1) | 할 일이 원래 날짜로 돌아간다(할 일 화면, 기록 화면에서 확인) |  |  |  |
| 4 | 할 일 둘을 옮겨 달라고 한다(예: "장보기랑 보고서 초안 화요일로 옮겨 줘") (조건 2) | `ui_result` 카드에 줄마다 "이전 → 지금" 날짜. 카드에 되돌리기 버튼이 없고, 카드가 활동을 모두 보이므로 활동 줄(확인 칸)은 없다 |  |  |  |
| 5 | 4의 토스트(6초 안) 또는 기록 화면에서 되돌리기를 누른다 (조건 2) | 둘 다 원래 날짜로 돌아간다(토스트 하나가 둘을 새것부터 되돌린다) |  |  |  |
| 6 | 할 일 셋 이상을 옮겨 달라고 한다(예: "이번 주 할 일 다음 주로 나눠 옮겨 줘") (조건 2) | `ui_period_list` 카드에 바뀐 줄마다 왼쪽 `--hue` 막대. 기간 밖으로 옮긴 것은 따로 묶인다. 활동 줄(확인 칸)이 남아 있다 |  |  |  |
| 7 | "이번 주 컨디션 어땠지"처럼 숫자나 진행을 묻는다 (조건 3) | `ui_block` 카드(숫자, 진행 막대 등). 답 글은 카드를 다시 읽어 주지 않는 한두 문장 |  |  |  |
| 8 | 1~7의 카드에 있는 버튼을 모두 훑어본다 (조건 4) | 버튼은 체크·완료, 확정, 이어 말하기, 앱 화면 열기뿐. 되돌리기는 카드가 아니라 알림(토스트)과 기록 화면에만 있다. 빼기, 우선순위, 시각 바꾸기 버튼은 없다 |  |  |  |
| 9 | 앱을 완전히 닫고 다시 열어 같은 대화를 연다 (조건 7) | 다시 그린 카드는 읽기 전용: 체크, 날짜 후보, 이어 말하기가 꺼지고 "기록에서 보기" 같은 화면 열기만 된다 |  |  |  |
| 10 | 밝게·어둡게, 색감 프리셋 하나 이상으로 바꿔 1~7의 카드를 본다 | 글자가 잘 읽히고 옆으로 밀리지 않는다 |  |  |  |

칸에는 `OK`, `FAIL`, `-`(확인 안 함)을 쓴다.
