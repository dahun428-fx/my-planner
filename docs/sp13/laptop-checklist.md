# SP13 노트북·아이폰 확인 목록 (객관적 위치)

개인 값은 이 파일에 적지 않는다. 가져올 파일과 리포트와의 차이 설명은 프로젝트 폴더 `social-level/`에만 있다.

1. **가져오기.** BE를 업데이트하고 멈춘 뒤 실행한다.
   `python -m my_planner standing import <프로젝트 폴더의 standing-2026-11-01.json>`
   → `imported: n, skipped: 0`. 다시 실행하면 `imported: 0, skipped: n`. BE를 다시 켠다.
2. **상태창.** 앱 상태창의 영역 줄에 "만족 n"과 "위치 n"이 함께 보이고, 아래에 "타고난 스탯"과 "객관적 위치 자세히 ›"가 있다. 자세히 화면에 시장 점수 둘, 레이더, 축별 막대, 측정값 목록이 보인다.
3. **리포트와 맞춰 보기.** 축 점수가 리포트 v2와 ±3 안인지 본다. 리포트 v2와 다를 수 있는 축: 자격, 집안, 경제력, 직업(이유는 `social-level/` 노트).
4. **사진 → 확인 카드.** 채팅에 인바디 사진을 올린다 → 확인 카드가 나온다 → 값 하나를 고쳐 저장 → 건강 위치가 바뀐다 → 토스트에서 되돌리기.
5. **대시보드.** 대시보드 상태창에는 위치가 없다(지금과 같다). 설정의 기기 목록에서 대시보드가 연결 코드(기기 종류 dashboard)로 붙어 있는지 본다. API 토큰으로 붙어 있으면 위치가 보이므로 연결 코드로 다시 붙인다.
