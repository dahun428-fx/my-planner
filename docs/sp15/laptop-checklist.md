# SP15 노트북·아이폰 확인 목록 (라이프 매니저와 전문가 패널)

개인 값은 이 파일에 적지 않는다. DB를 열어 본 결과도 저장소나 대화에 붙이지 않는다. 숫자를 적으라는 줄은 걸린 시간·턴 수·개수뿐이다.

0. **스파이크 S1 다시 돌리기.** 클라우드에서 한 번 돌았지만 가짜 도구라서 시간 값이 짧다. 노트북에서 `.venv\Scripts\python spikes\sp15_s1.py`를 돌려 `full6_seconds`·`full6_turns`·`full2_seconds`·`full2_turns` 줄을 `docs/spikes/2026-11-sp15.md`에 갈음한다. 판정 줄(`agents_ok`, `deny_hook_ok`, `builtin_agent_blocked`)이 하나라도 False면 여기서 멈추고 스펙 안 B를 연다.
1. **업데이트.** BE를 업데이트하고 다시 켠다. 그 전에 DB 백업이 하나 더 생겼는지, 시작 로그에서 마이그레이션 024(`user_version` 24)가 돌았는지 본다.
2. **상대 고르기(1장 1).** 아이폰 앱 채팅 시트에 비서 | 운동메이트 | 라이프 매니저(나침반)가 있고, 라이프 매니저 대화 목록이 따로다.
3. **한 목소리(1장 2).** "연봉이 오르면 결혼 시장 점수는 어떻게 돼?"를 보낸다. 답 아래 "전문가 소견 n개"(많아야 2)가 있고, 펴면 원문이 보인다. 원문 앞뒤에 `[Subagent hand-back]` 머리말이나 `agentId`·`<usage>` 꼬리가 남아 있지 않다. 로그에 `brain_call` 한 줄.
4. **패널 제안(1장 3·4).** "이번 주 뭐부터?" 칩 → 카드 하나, "근거 보기"에 근거 제목과 링크. 링크가 그 기록 화면으로 간다. 외부 기준만 있는 내용은 답 안의 "참고:" 문단에만 나온다.
5. **주간 제안 수(1장 5).** 매니저 머리 아래 "이번 주 제안 n개 더 받을 수 있어요"가 카드를 받을 때마다 줄고, 0이면 카드가 나오지 않는다.
6. **받기·버리기(1장 6).** 받기 → 할 일 탭에 그 할 일. 같은 영역에서 버리기 "너무 큼"을 두 번 → 더보기 › 내가 한 말에 한 줄. 그 줄의 "지우기"를 누르면 사라지고 되돌리기 토스트가 뜬다.
7. **질문 먼저(1장 7).** 관계 영역을 물으면 카드 대신 질문이 오고, 답하면 내가 한 말에 남는다.
8. **목표 숫자·예측(1장 8·9).** 운동 목표를 물으면 내 속도 표에서 출발한 숫자가 나온다. "90일 뒤 체지방은?"을 물으면 DB `panel_predictions`에 한 줄 생긴다(`sqlite3 -readonly`로 개수만 본다).
9. **전체 진단(1장 11, 10장).** 분기 회고에서 영역 점수를 저장하면 비서 답 아래 "전체 진단 해 볼까요?" 버튼이 하나 생기고, 누르기 전에는 아무것도 돌지 않는다. 버튼이나 "전체 진단" 칩을 누르면 몇 분 뒤 답이 오고, 상태창 › 인생 리포트(`/status/report/`)에 리포트가 있고, 칩은 "오늘은 이미 했어요"가 된다. 로그에서 걸린 시간과 `brain_call` 턴 수를 보고 `limits.full_diagnosis`가 넉넉한지 적는다(숫자만).
10. **인생 리포트 화면.** 아이폰에서 장 순서가 세 통로 요약 → 점수판 → 지렛대 지도 → 전문가 소견 → 3년 하면/안 하면 → 90일 로드맵 → 이번 주 → 남은 질문이고, 가로 스크롤이 없다. 다크 모드에서도 차트 선이 보인다.
11. **하루 끝(1장 12·13).** 다음 날 아침 로그에 `agent_dayend` 두 줄(`mate`, `manager`)이 있고, 아침 브리핑 끝의 관찰 줄은 많아야 하나다. 라이프 매니저가 따로 푸시·텔레그램을 보낸 적이 없다.
12. **대시보드.** 대시보드 화면이 바뀌지 않았다. 대시보드를 기기 짝짓기(6자리 코드)로 연결해 두었다면 `/life-reports`가 403이다. API 토큰으로 연결했다면 SP13 ⑮처럼 그대로 보이니, 기기 짝짓기로 바꾼다.
13. **개인 값.** 로그 파일에서 연봉·자산·체성분 숫자를 검색해 나오지 않는지 본다.
