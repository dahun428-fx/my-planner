# 사용자와의 유일한 통로는 텔레그램 봇 롱폴링이다

웹훅은 집 노트북에 공개 주소가 필요하고, 자체 앱은 만들 일이 많다. 그래서 텔레그램 봇 하나를 Dahun의 계정 ID에만 묶고 `getUpdates` 롱폴링으로 받는다. 메시지는 텔레그램 서버를 거치는 것을 받아들였다. 대신 텔레그램은 받아 가지 않은 메시지를 24시간까지만 보관하므로, 그보다 오래 꺼져 있으면 메시지가 사라질 수 있다.

상태: SP3-4 스펙 초안(2026-10-24)이 승인되면 [ADR 0007](0007-http-api-inside-be-single-writer.md)이 이 결정을 일부 대체한다. 운영 앱이 두 번째 통로가 되고, 텔레그램은 롱폴링 그대로 남는다.
