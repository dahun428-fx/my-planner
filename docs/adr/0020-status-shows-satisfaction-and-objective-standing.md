# 0020. 상태창은 영역마다 "만족"과 "객관적 위치"를 나란히 보이고, 위치 하락은 이유를 나눈다

- 날짜: 2026-11-01
- 상태: 초안 (Dahun 결정 Q1 C, Q7 C, 2026-11-01)

Dahun은 공식 통계와 비교한 자기 위치를 상태창에서 계속 보고 싶어 한다. 6영역(할 일·습관·경험치가 이미 묶인 틀)을 유지하고, 영역마다 분기 회고의 만족 점수 옆에 객관적 위치(0~100)를 둔다. 키·학벌·집안은 "타고난 스탯"으로 따로 두고 다시 채점하지 않는다. 같은 영역에서 "만족 8인데 위치 30"처럼 나오는 차이가 가장 쓸모 있는 정보였다(2026-11-01 점검).

객관적 위치는 내가 아무것도 안 해도 떨어질 수 있다(기준표 갱신, 나이 구간 이동). 그래서 분기 스냅숏으로 변화를 "내 변화"와 "세상 변화"로 나누고, 내 변화로 떨어질 때만 디버프를 붙인다(ADR 0006의 "신호지 벌이 아님"을 지킨다). 점수는 두뇌가 매기지 않고 저장소의 기준표 파일과 순수 함수가 계산한다(같은 입력에 같은 점수, 근거 추적).

대가: 측정값(연봉, 자산, 체성분)이 노트북 DB에 쌓이고, 확인 카드를 만들 때와 SP15 라이프 매니저 앞머리로 Anthropic에 간다. 대시보드는 링크만 있으면 열리는 화면이라 위치 값을 받지 않는다. 기준표는 해마다 손으로 갱신해야 한다. 상세는 [SP13 스펙](../superpowers/specs/2026-11-01-sp13-objective-standing-design.md).
