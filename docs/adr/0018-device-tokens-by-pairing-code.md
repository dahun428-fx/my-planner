# 새 기기는 6자리 연결 코드로 붙고, BE가 기기마다 따로 토큰을 준다

지금은 모든 기기가 노트북 `.env`의 `API_TOKEN` 하나를 손으로 옮겨 넣는다. 43자 토큰을 옮기는 일이 번거롭고, 옮기는 사이 채팅이나 메모에 남기 쉽고, 기기 하나를 잃어버리면 토큰을 바꿔 모든 기기에 다시 넣어야 한다. 그래서 이미 연결된 기기(또는 노트북의 `my_planner pair` 명령)가 5분짜리 한 번 쓰는 6자리 코드를 만들고, 새 기기가 그 코드를 `POST /api/v1/pair`에 내면 BE가 그 기기만의 토큰을 준다. BE는 토큰의 sha256만 `devices` 표에 두고, 기기는 목록에서 하나씩 끊는다. API 토큰(`API_TOKEN`)은 그대로 통한다(이미 연결된 기기와 비상 복구). BE는 계속 tailnet 안에만 열리므로(ADR 0008) 코드는 tailnet에 들어온 기기만 낼 수 있다. 대가: 인증이 메모리의 기기 토큰 사전과 DB 한 표에 기대고, 인증 없이 받는 경로(`/pair`)가 하나 생긴다. 틀린 코드는 같은 실패 제한에 센다. 기기 토큰은 API 토큰과 같은 경로를 열므로(`/internal/notify` 빼고), 훔친 기기 토큰으로 끊기기 전에 다른 기기를 붙일 수 있다. 그때는 `다른 기기 모두 끊기`를 쓴다. 상세는 [기기 연결 코드 스펙](../superpowers/specs/2026-10-26-device-pairing-design.md).
