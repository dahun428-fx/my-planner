# 0021. 마스터(비서)가 맨 위에 있고, 사건은 코드가 아래층으로 전하며, 말하는 건 마스터 하나다

- 날짜: 2026-11-01
- 상태: 초안 (Dahun 2026-11-01, Q8 B). [ADR 0019](0019-workout-mate-is-a-second-agent-in-be.md)의 "두 상대는 대등하다" 부분을 대체한다

Dahun은 마스터(총괄비서) 아래에 운동메이트와 라이프 매니저가, 라이프 매니저 아래에 전문가 6명이 있고, 할 일·일정·메모 같은 정보가 위에서 아래로 전해져 각자 판단하는 구조를 원한다. 사건마다 두뇌를 부르면 할 일 하나에 여러 호출이 나가 구독 한도가 바닥나고, 층마다 요약하면 정보가 깎이고, 여러 상대가 각자 말을 걸면 압박이 된다.

그래서 전달은 코드가 한다: 쓰기 경로가 같은 트랜잭션에서 사건 한 줄(종류, id, 영역)을 남기고, 라우팅 규칙이 아래층 상대의 받은편지함에 넣는다. 아래층은 하루 끝에 한 번(그리고 직접 대화할 때 즉시) 두뇌를 부르고, 원문 기록을 직접 읽는다. 결과는 관찰 한 줄이고, 마스터가 아침 브리핑에 많아야 하나 붙인다. 아래층은 먼저 말하지 않는다.

대가: 판단이 하루 늦다(Q8에서 받아들임). 쓰기 경로마다 사건 쓰기가 늘어 쓰기 경로 감시 테스트가 커진다. 상세는 [SP14 스펙](../superpowers/specs/2026-11-01-sp14-master-hierarchy-design.md).
