# 할 일과 회차는 SQLite가 원본이고, md는 사람이 읽는 사본이거나 서술 기록이다

처음에는 md 파일을 원본으로 하려 했다. 하지만 우선순위 3개 상한, 회차 중복 방지, 크래시 뒤 재실행 판정을 트랜잭션과 제약으로 지키려고 SQLite(`state/planner.db`)를 원본으로 바꿨다. `data/exports/tasks.md`는 매번 다시 만드는 사본이다. 원문 기록, 회고, 기억 카드는 md가 원본이다. 검색 색인(`state/index.db`)은 언제든 다시 만들 수 있어 백업하지 않는다. 그래프 DB와 별도 벡터 DB는 쓰지 않는다.
