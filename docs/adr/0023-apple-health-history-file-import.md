# 0023. 애플 건강앱 운동은 내보내기 파일을 노트북에서 가져와 따로 된 표에 둔다

- 날짜: 2026-11-07
- 상태: 확정 (Dahun 2026-11-07 "과거 이력 가져오기만")

운동메이트는 메이트 대화에서 말로 남긴 운동만 알아서, 워치·건강앱에 쌓인 운동을 물으면 "기록이 없다"고 답했다(2026-11-07). 운영 앱은 PWA라 HealthKit을 읽을 수 없고, 건강 데이터를 읽는 것은 앱스토어 네이티브 앱만 할 수 있다. 직접 앱을 만드는 길(연 $99 개발자 등록)은 SP5에서 하지 않기로 했고, 매일 자동으로 보내 주는 남의 앱(Health Auto Export)은 그 기능이 유료다. Dahun은 무료인 "이력 가져오기만"을 골랐다.

그래서 건강앱 "모든 건강 데이터 내보내기" 파일(export.zip)을 노트북에서 `python -m my_planner health import`가 BE를 멈춘 채(잠금을 잡고) 스트리밍으로 읽어, 운동만 새 표 `health_workouts`에 넣는다. 처음 한 번 지난 이력을 채우고, 그 뒤로는 Dahun이 원할 때 다시 내보내 노트북 스크립트(`scripts/health_import.ps1`: 멈춤 → 가져오기 → 다시 켬)로 더한다. 같은 운동은 종류·시작 ±60초·길이 ±1분으로 찾아 덮어쓴다. 운동 기록(SP12, 세트·무게)과 표를 나누고, 읽는 쪽(메이트 앞머리, `list_workouts`, 운동 화면)이 합쳐 보인다. 새 HTTP 쓰기 경로와 토큰은 없다.

대가: 마지막으로 가져온 날 이후의 운동은 메이트가 모른다. 메이트는 "어디까지 가져왔나"를 말하고, 운동을 안 했다고 말하지 않는다. 가져올 때마다 Dahun이 폰에서 파일을 만들어 노트북으로 옮겨야 하고, 그 파일에는 건강 데이터 전체가 들어 있어 가져온 뒤 지우게 한다. 경험치는 가져온 날 기준 7일 안의 운동에만 붙어, 가끔 가져오면 일부 날은 경험치가 없다(보너스는 붙는다). 운동 종류·시간·심박 요약이 메이트 두뇌로 가서 Anthropic에 간다. 경로·심박 시계열·기기 이름은 저장하지 않는다. 매일 받기가 필요해지면 같은 표 위에 내보내기 앱 경로를 따로 설계한다. 상세는 [SP16 스펙](../superpowers/specs/2026-11-07-sp16-apple-health-design.md).
