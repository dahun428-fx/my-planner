# 0023. 애플 건강 데이터는 내보내기 앱이 좁은 토큰 경로로 보내고, 지난 이력은 내보내기 파일로 한 번 채운다

- 날짜: 2026-11-07
- 상태: 초안 (Dahun 확인 전, SP16 스펙 5장 Q1)

운동메이트는 메이트 대화에서 말로 남긴 운동만 알아서, 워치·건강앱에 쌓인 운동을 물으면 "기록이 없다"고 답했다(2026-11-07). 운영 앱은 PWA라 HealthKit을 읽을 수 없고(SP8 4장), 네이티브 앱은 만들지 않기로 했다(SP5).

그래서 두 길을 둔다. **매일**: 아이폰의 내보내기 앱(Health Auto Export, 유료 프리미엄)이 정해진 주기로 운동·걸음·수면·몸무게를 JSON으로 `POST /api/v1/health/export`에 보낸다. 이 경로는 SP8의 단축어 토큰(`BODY_TOKEN`)만 받고, 운동은 새 표 `health_workouts`에 운동 id 또는 같은 종류·시작 ±60초·길이 ±1분으로 같은 운동을 찾아 덮어쓴다. **한 번**: 건강앱 "모든 건강 데이터 내보내기" 파일을 `python -m my_planner health import`가 BE를 멈춘 상태에서 스트리밍으로 읽어 같은 표에 넣는다. 운동 기록(SP12, 세트·무게)과 표를 나누고, 읽는 쪽(메이트 앞머리, `list_workouts`, 운동 화면)이 합쳐 보인다.

단축어만 늘리지 않은 이유: 기본 단축어 동작으로는 운동 종류·심박 요약을 얻기 어렵고, 폰이 잠겨 있으면 건강 데이터 읽기가 실패한다는 보고가 있다. Strava 같은 외부 서비스를 거치지 않은 이유: 데이터가 한 번 더 바깥으로 나가고 노트북 BE가 외부 OAuth를 들고 있어야 한다(P5).

대가: 유료 앱 하나에 기대고, 그 앱의 JSON 형식이 바뀌면 파서를 고쳐야 한다(모르는 키는 무시해 멈추지는 않게 한다). `BODY_TOKEN`이 통하는 경로가 둘로 늘어 새면 가짜 운동을 넣을 수 있다. 숨기면 보너스에서는 빠지지만 이미 생긴 경험치는 줄지 않는다(하루 5, 받는 순간 지난 7일까지라 많아야 35). SP8의 "몸 기록에는 경험치 없음"을 건강앱 운동에 한해 바꾼다. 운동 종류·시간·심박 요약이 메이트 두뇌로 가서 Anthropic에 간다. 경로·심박 시계열·기기 이름은 저장하지 않는다. 상세는 [SP16 스펙](../superpowers/specs/2026-11-07-sp16-apple-health-design.md).
