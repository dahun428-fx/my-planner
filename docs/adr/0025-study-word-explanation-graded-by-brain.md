# 0025. 공부 앱의 단어 설명 채점은 BE 두뇌의 도구 없는 한 번 호출로 한다

- 날짜: 2026-11-20
- 상태: 제안 (Dahun 2026-11-20 "my-planner처럼 claude code sdk를 써서 추가해보면?")

공부 앱(AI 듀오링고, ADR 0024)의 "AI 사전 퀴즈"는 뜻을 보고 용어를 고르는 방향만 있다. Dahun은 반대로 용어를 보고 자기 말로 설명하면 AI가 맞은 점, 빠진 점, 틀린 점을 짚어 주기를 원한다. 공부 앱은 정적 PWA라 API 키를 둘 곳이 없고, 따로 서버 함수와 API 과금을 두는 대신 이미 진도를 맞추는 이 BE와 이 BE가 쓰는 구독 Claude(Agent SDK)를 쓰기로 했다.

그래서 BE에 `POST /api/v1/study/grade`를 둔다. 본문은 `{term, meaning, answer}`(용어, 앱의 참고 뜻풀이, 학생 설명)이고 답은 `{score, verdict, good, missing, wrong, tip}`이다.

**두뇌 호출.** 사진 읽기(SP10 5.4)·대화 요약(SP9 7.2)과 같은 틀이다: 실행 종류 `study_grade`는 `NO_TOOL_KINDS`에 들어 도구가 없고, `max_turns = 1`, `persist_session = False`, 끝나면 세션 파일을 지운다. 두뇌 큐를 사용자 메시지와 같은 차례로 탄다(사용자가 기다린다). 지시문은 `prompts/study_grade.md`이고 학생 설명은 `<answer>`로 싸서 그 안의 지시를 따르지 않게 한다. 도구가 없으므로 설명에 무엇을 써도 비서의 데이터에 닿지 않는다.

**토큰과 출처.** 진도와 같은 `STUDY_TOKEN`만 받고 같은 출처 규칙을 따른다(ADR 0024). 새 토큰이나 설정을 더 넣지 않아도 진도 동기화를 켠 기기는 바로 채점을 쓴다.

**몫.** 모든 호출이 `daily_brain_calls`에 든다. 채점은 그 가운데 `limits.study_grade_reserve_calls`(기본 20)를 비서 몫으로 남기고 그 앞까지만 쓴다. 넘으면 `429 study_grade_limit`. 로그인·결제 문제나 사용 한도 대기 중이면 두뇌를 부르지 않고 `503`이다. 새 표와 마이그레이션은 없다.

**남기는 것.** 아무것도 저장하지 않는다. 원문 기록, 활동 기록, 경험치, 사건이 없다. 로그에는 `study_graded {score, chars}`만 남긴다(용어와 설명은 남기지 않는다).

대가: 노트북이 꺼져 있거나 기기가 tailnet 밖이면 채점할 수 없다. 앱은 그때 참고 뜻풀이를 보여 주고 스스로 채점하게 한다(`503`·연결 실패도 같다). 채점 한 번에 수 초~수십 초가 걸리고 그동안 같은 큐의 비서 메시지는 기다린다.
