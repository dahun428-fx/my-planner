# 운영 앱은 Vercel의 정적 PWA이고, 읽은 화면 일부를 폰에 7일 남긴다

Dahun은 아이폰에서 비서를 운영할 앱을 원하고, 스토어 배포나 연 $99 개발자 계정은 원하지 않는다. 그래서 운영 앱은 대시보드(ADR 0008)처럼 Next.js 정적 내보내기를 Vercel에 올리는 PWA로 만들고, 폰 브라우저가 Tailscale로 BE `/api/v1`을 직접 부른다. Vercel에는 서버 코드가 없고, 두뇌와 데이터와 규칙은 모두 BE에 남는다. 알림은 BE가 보내는 웹 푸시이고, 아이폰은 홈 화면에 추가한 앱에서만 받는다(iOS 16.4 이상). 대시보드와 다른 점 하나: 노트북이 꺼져 있어도 오늘 할 일을 볼 수 있게(Dahun 결정) 마지막으로 받은 `GET /today`, `GET /week`, 오늘 체크인 요약을 IndexedDB에 받은 시각과 함께 남긴다. 같은 저장소에 대화 조각(최근 200개)과 UI 카탈로그도 둔다. 모두 7일이 지나거나 "이 기기 연결 해제"를 하면 지운다. 대가: 폰을 잃어버리면 그 범위의 할 일과 최근 대화가 보일 수 있다. 오프라인에서 쓰기를 모아 두었다 보내지는 않는다(그 사이 바뀐 상태를 덮지 않으려고). 상세는 [SP5 스펙](../superpowers/specs/2026-10-24-sp5-ops-app-design.md) 4장.
