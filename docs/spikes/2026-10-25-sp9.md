# SP9 스파이크 (S1~S3)

## S1 빈 번호 거부
`migrate()`는 마이그레이션 파일 번호가 1부터 이어지지 않으면 적용 전에 `MigrationGapError("missing migration 013")`을 낸다. `pytest tests/test_migrations.py -k gap -q` 통과.

## S2 FTS5 trigram
- 클라우드 컨테이너: SQLite 3.45.1, `fts5(x, tokenize='trigram')` 생성 오류 없음. 통과(3.34 이상).
- 노트북: Dahun 결과 대기 중(한 줄로 받는다. 티켓을 막지 않는다). 안 되면 `LIKE` 검색으로 바꾼다.

## S3 세션 파일 위치
- `scripts/spike_session_path.py <session_id>`가 `~/.claude/projects/<cwd를 -로 바꾼 이름>/<session_id>.jsonl`을 찾아 한 줄로 찍는다(없으면 projects 아래 전체 검색, 그래도 없으면 종료 코드 1).
- 노트북 확인과 아이폰 `.ics` 구독 확인은 SP9-11로 넘긴다.
