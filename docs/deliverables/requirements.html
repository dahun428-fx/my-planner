11미정 · 확인 필요

이 문서에서 확정하지 못한 것입니다. 확인되면 상태 칩과 RTM을 고칩니다.

  • 확인 필요 SP5-A12 실기기 수용 테스트를 했는지 기록이 없다. 이 문서는 “실기기 확인 대기”로 둔다(SP5-FR-15).
  • 확인 필요 SP34-00 스파이크 S7~S12 중 노트북 항목(이슈 #42 열림)의 결과. AS-10·AS-13의 상태가 이것에 달렸다.
  • 확인 필요 SP7-00(S12 도구 35개 재확인)의 결과 기록을 찾지 못했다.
  • 확인 필요 운영 앱 시험은 시험 결과서가 돌렸다(vitest 541 · Playwright 19 통과). 요구별 시험 이름은 시험 결과서와 맞대어 보지 않았다. SP5 요구의 “구현됨”은 시험 파일이 main에 있다는 뜻이다.
  • 미정 SP6 자동 복구 스파이크 S1~S6이 실패하면 SP6R-FR-06·09·10의 방식이 바뀐다(스펙 §10의 대안).
  • 미정 SP2 기억 계층은 스펙이 없어 요구사항을 두지 않았다.
