2화면 흐름도

화면은 두 갈래로 열립니다. 시각이나 상태가 여는 화면(비서가 먼저)과 사용자의 입력이 여는 화면입니다.

범례 · 흐름도 표기
  • 둥근 끝 상자트리거(시각, 깨어남, 사용자 입력)
  • 굵은 테두리 상자주요 화면 (화면 ID)
  • 노란 상자예외·고정 안내 화면
  • 마름모하네스 판정
  • 점선 화살표 · 점선 상자합쳐 보냄 / 화면이 아닌 처리

3공통 화면 규칙과 표기

모든 스토리보드에 같은 규칙이 적용됩니다. 와이어프레임의 날짜와 할 일 제목은 예시입니다.

범례 · 와이어프레임 요소
  • 왼쪽 말풍선비서(봇)가 보낸 메시지
  • 오른쪽 말풍선사용자 메시지 (내용은 예시)
  • 회색 막대두뇌 답변(자유 문장). 원문을 정하지 않으므로 그리지 않음
  • 초록 고정폭 줄하네스가 만든 확인 문구 (두뇌 답 아래, 같은 메시지)
  • 점선 상자하네스 고정 문구. 실제 텔레그램에서는 일반 봇 메시지로 보임
  • 청록 버튼인라인 키보드 버튼. 회색은 보조 버튼
  • 1번호 표식설명 표의 같은 번호 행. 올리거나 포커스하면 함께 강조
