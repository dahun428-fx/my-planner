  • 비서(secretary)는 역할 전체, 봇(bot)은 텔레그램 입출력, 두뇌(brain)는 Claude, 하네스(harness)는 두뇌 바깥의 모든 것입니다. BE(backend)는 그 하네스와 HTTP API를 담은 노트북 프로세스 하나입니다.
  • 헷갈리기 쉬운 짝이 셋 있습니다: 도구와 HTTP API, 되돌리기와 배포 롤백, 놓친 회차와 회차 지연.
  • “초안” 칩이 붙은 15개는 GLOSSARY.md에 “초안”으로 적혀 있고 Dahun 확인 전입니다.
  • 하지 않는 것(체력 피해, 연속 기록, 기간 한정 보상)도 용어로 고정해 두었습니다. 습관 체크도 연속 일수를 세지 않습니다.
  • 바꾸려면 GLOSSARY.md를 먼저 고칩니다. 스펙 용어를 GLOSSARY.md에 올릴지는 미정입니다.
