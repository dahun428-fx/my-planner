BE와 바깥이 주고받는 모든 약속

운영 앱과 대시보드는 HTTP API로, 텔레그램은 명령과 버튼으로, 두뇌는 도구로 BE와 이야기합니다. 이 문서는 각 접점의 모양, 인증, 응답, 오류를 OpenAPI 문서처럼 한 곳에 적습니다. 예시의 값은 모두 꾸며 낸 것입니다.

접점은 여덟 가지이고, 모두 노트북의 BE 프로세스 하나에서 끝납니다. 데이터를 바꾸는 접점은 결국 같은 도구 함수를 부릅니다.

  • HTTP API는 https://<기계>.<tailnet>.ts.net/api/v1 아래 26경로입니다. 모두 Bearer 토큰이 필요합니다. tailnet 밖에서는 닿지 않습니다.
  • 앱 채팅(POST /chat)만 SSE 스트림으로 답합니다. 나머지는 JSON 한 덩어리입니다.
  • 쓰기 요청(/chat, /actions, /undo)은 client_msg_id가 꼭 있어야 합니다. 같은 값으로 다시 보내면 같은 답이 옵니다.
  • 오류는 언제나 {"error":{"code","message"}} 모양입니다. message는 화면에 그대로 띄워도 되는 한국어 한 줄입니다.
  • 두뇌 도구는 텔레그램 대화에 28개, 앱 대화에 35개가 열립니다. 앱에만 화면 조각 4개와 고정 카드 3개가 더해집니다. G-BE2(PR #139, 열림)가 병합되면 앱 39개(조각 4개 더함).

2공통 규칙

모든 경로에 똑같이 걸리는 주소, 인증, 시간, 중복 방지, 요청 관문, CORS, 오류 모양입니다.

기본 약속
항목규칙근거
기본 주소https://<기계>.<tailnet>.ts.net/api/v1. BE는 127.0.0.1:8787에만 열고, tailscale serve가 HTTPS 443을 넘겨 줍니다. Funnel은 쓰지 않습니다.config.py ApiConfig
인증Authorization: Bearer <토큰>. 토큰은 python -m my_planner gen-token으로 만들어 .env에 둡니다. 비교는 hmac.compare_digest입니다. 쿠키는 쓰지 않습니다.api/auth.py
토큰 틀림 제한1분 안에 10번 틀리면 1분 동안 모든 요청에 429 too_many_auth_failures입니다.api/auth.py
본문Content-Type: application/json, UTF-8. 64KB를 넘으면 413 too_large입니다. 모르는 필드는 400 invalid_request입니다.api.max_body_kb
시간응답의 시각은 UTC이고 끝에 Z를 붙입니다(2026-10-24T09:00:00Z). 날짜는 YYYY-MM-DD, 주는 YYYY-Www, 달은 YYYY-MM, 분기는 YYYY-Qn입니다. "오늘"은 새벽 4시 경계로 셉니다.api/models.py
중복 방지/chat, /actions, /undo는 client_msg_id(1~200자)가 꼭 있어야 합니다. 같은 경로에 같은 값이면 저장한 답을 돌려줍니다(2일 보관, api_idempotency). 다른 경로에 쓴 값이면 409 conflict입니다.SP3-4 §6.1
읽기와 쓰기GET은 요청마다 새 읽기 전용 연결(mode=ro)로 읽습니다. 쓰기는 모두 Dispatcher의 줄 하나를 지납니다(ADR 0007).api/server.py
스키마모든 응답 모델의 JSON Schema는 GET /schema로 받습니다. 앱과 대시보드는 이것으로 types.gen.ts를 만들고 응답을 검사합니다.api/models.py
