하위 프로젝트별 범위와 완료 조건 (마스터 §4 원문)
#범위완료 조건의존상태
SP1 비서 코어봇(본인 잠금), harness core, 두뇌 세션, loop(아침 브리핑, 저녁 체크인, 주간 회고, 따라잡기), 할 일과 컨디션 도구와 SQLite, 원문 기록 저장, 시스템 로그, 작업 스케줄러 등록7일간 runs 테이블의 예정 회차가 모두 done 또는 따라잡기 규칙에 맞는 skipped이고, 텔레그램으로 할 일을 추가·완료·이동할 수 있다없음코드 병합 · 수용 테스트 대기
SP2 기억 계층정리 루프, 기억 카드 생성·갱신·감쇠, 로컬 임베딩 + sqlite-vec + FTS5, search_memory, /memory2주 사용 후 “예전에 ~했을 때”류 질문에 근거 카드와 함께 답한다SP1예정
SP3 인생 곡선 + 상태창과거 그래프 인터뷰, 월·분기·연 회고 루프, 사다리 점수와 영역 점수 초안, 사건과 챕터, 레벨·경험치·스탯·디버프·퀘스트, /status, 차트 이미지첫 월간 회고에서 점수 초안과 레이더 차트를, 첫 분기 회고에서 곡선 그래프를 받는다SP1, SP2예정
SP4 웹 대시보드로컬 웹 화면: 상태창, 인생 곡선, 퀘스트, 기억 카드 열람브라우저에서 /status와 같은 데이터를 보고, 곡선을 기간별로 확대·축소할 수 있다SP3예정
아직 정하지 않은 것SP2~SP4의 티켓 분해와 순서는 각 스펙에서 정합니다: 미정(SP2~SP4 스펙에서 결정). SP2 착수 전에 bge-m3 용량과 GPU 사용을, SP4 착수 전에 UI UX Pro Max 스킬 설치 여부를 확인합니다(마스터 §7).
