텔레그램으로 먼저 말을 거는 개인 AI 비서, my-planner

인생 곡선을 점검하고 일·주·월·분기·년 주기의 할 일과 회고를 이어 가도록 돕는 개인 AI 비서입니다. 비서는 텔레그램으로 먼저 말을 걸고 정리와 초안을 대신 하며, 결정은 사용자가 합니다. 이 사이트는 첫 하위 프로젝트 SP1(비서 코어)의 산출물을 산업 표준 양식으로 정리합니다.

작성일 2026-10-23 실행 환경: 사용자 노트북(Windows 11) 한 대 단일 사용자 전용

산출물 지도

요구에서 운영까지 생애주기 순서로 놓았습니다. 각 문서 머리에 따른 표준을 적고, 요약 → 그림 → 상세 표 순서로 읽히게 썼습니다.

요구무엇을
요구사항 정의서 ISO/IEC/IEEE 29148 · RTM 기능·비기능 요구, MoSCoW 우선순위, 인수 기준, 요구사항 추적 매트릭스. 검토 중requirements.html
설계어떻게
아키텍처 정의서 C4 모델 (Context · Container · Component) 텔레그램, 하네스, 두뇌, 도구, 저장소의 경계와 관계. 검토 중architecture.html 업무 흐름도 BPMN 2.0 아침 브리핑·저녁 체크인·주간 회고, 따라잡기, 초안 확정 흐름. 검토 중process-flows.html 시퀀스·상태 다이어그램 UML 2.5 메시지 처리 순서, 회차와 할 일의 상태 전이. 검토 중behavior.html 화면설계서 스토리보드 · 번호 콜아웃 텔레그램 대화 화면, 인라인 버튼, 명령 응답, 고정 안내 문구 원문. 검토 중screens.html ERD · 테이블 정의서 IE(까마귀발) 표기 SQLite 원본 표의 컬럼, 타입, 키, 제약, 기본값. 검토 중database.html 인터페이스 정의서 호출자 → 제공자 · 입출력 · 오류 도구 12개, 텔레그램 Bot API, Agent SDK 호출 계약. 검토 중interfaces.html
