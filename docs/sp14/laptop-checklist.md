# SP14 노트북·아이폰 확인 목록 (총괄비서 아래 위계)

개인 값은 이 파일에 적지 않는다. DB를 열어 본 결과도 저장소나 대화에 붙이지 않는다.

1. **업데이트.** BE를 업데이트하고 다시 켠다. 시작 로그에서 마이그레이션 023이 돌았는지(`user_version` 23) 본다.
2. **사건이 쌓인다.** 앱에서 할 일 하나를 끝내고, 메이트에게 운동 하나를 말한다. BE의 DB 파일을 `sqlite3 -readonly`로 열어
   `SELECT kind, ref, area, origin FROM agent_events ORDER BY id DESC LIMIT 5`
   에 `task_done`·`workout_logged`가 있고, 제목·본문 칸이 없는지 본다.
3. **즉시 판단.** 아이폰 앱에서 채팅 시트를 열고 운동메이트를 고른다. 이름 아래 "새로 본 것 n개"가 보인다(열기만으로는 아무 답도 오지 않는다). 메이트에게 "오늘 뭐 할까?"를 보내면 첫 답이 새 일정·기록을 언급한다. 시트를 닫았다 열면 "새로 본 것"이 사라진다.
4. **하루 끝 판단.** 다음 날 아침 로그에 `agent_dayend` 줄(`agent=mate`, `result=ok` 또는 `empty`)이 하나뿐이고, `brain_call` 가운데 하루 끝 판단은 하나다.
5. **아침 브리핑.** 그날(또는 다음 날) 아침 브리핑 끝에 덤벨 픽토그램과 "운동메이트: …" 줄이 많아야 하나 있다. 메이트가 따로 푸시·텔레그램을 보낸 적이 없다.
6. **비서 메모.** 더보기 › 비서 메모를 누르면 지난 7일 관찰이 펼쳐진다(오프라인일 때는 이 줄이 숨는다).
7. **노트북을 하루 이상 꺼 둔 뒤.** 켠 날 `agent_dayend`가 한 번만 돌고(`events`가 며칠치 합), 두뇌 호출 상한에 걸리지 않는다.
8. **대시보드.** 대시보드 화면은 바뀌지 않았다.
